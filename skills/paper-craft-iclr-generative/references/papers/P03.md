# P03: Spectral Normalization for Generative Adversarial Networks

Takeru Miyato; Toshiki Kataoka; Masanori Koyama; Yuichi Yoshida. **ICLR 2018**. [Official paper](https://openreview.net/forum?id=B1QRgziT-) · [Full text read: arXiv:1802.05957v1](https://arxiv.org/pdf/1802.05957v1).

Source locations: Sections 2–4; Figures 2–5; Table 2; Appendices A–E.

## Writing move: Connect a predicted mechanism to a revealing measurement

Spectral normalization explains the constraint it wants before presenting the normalization rule: control the largest singular value without forcing all directions to have equal strength. This gives its comparison with weight normalization and orthogonal regularization a scientific purpose. The singular-value distributions in Figure 3 return to that explanation, while the feature-dimension experiment asks when the additional freedom matters.

## Experimental logic

Optimizer-setting sweeps examine robustness, best-score tables examine quality, and timing measures computational overhead. Those are separate arguments. Table 2 includes cases where orthogonal regularization has better FID under the standard CNN; the stronger ResNet results use further architecture and objective choices. The dimension sweep is particularly useful because it changes the condition under which the proposed mechanism should help.

## Detail placement

Explain the spectral constraint and the approximate power iteration in the method; leave full layer tables and optimizer grids to the appendix. Keep important architecture changes alongside cross-method comparisons. The learned-scale extension with gradient penalty is a distinct configuration.

## Interpretation

The implementation uses an approximate norm and reshaped convolutional weights; do not turn it into an unconditional exact global Lipschitz guarantee. Its quality, robustness, and overhead comparisons each have their own setting. The combination with gradient penalty supports complementarity, not a claim that every alternative is obsolete.
