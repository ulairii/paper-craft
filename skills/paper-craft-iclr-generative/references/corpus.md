# ICLR generative models: source papers

Ten accepted ICLR papers on variational inference, invertible flows, adversarial training, diffusion sampling, vector-field learning, text-to-image systems, and reward-based adaptation.

All ten main texts and the specified relevant appendices were read. Official conference records establish the venue. P01–P08 use versioned author arXiv PDFs, which are not asserted to be identical to the conference versions; P09–P10 use official proceedings PDFs. Source versions and reading coverage appear in the metadata. Figure discussions use extracted text and captions, not visual styling. The lessons interpret scientific presentation rather than establish what caused acceptance.
