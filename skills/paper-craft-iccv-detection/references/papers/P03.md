## Writing move: Find the small condition that makes an obvious extension work

Mask R-CNN calls the extra mask branch a natural extension, then explains why it needs spatial alignment that box classification can tolerate losing. RoIAlign and independent binary masks make the simple extension effective. The paper sells an enabling framework rather than pretending that adding an output branch is itself mysterious.

## Experimental logic

RoIWarp already uses bilinear sampling but retains quantization; this comparison identifies alignment as the relevant change. Higher-stride features and stricter localization metrics make its effect more visible. Box-only evaluation separates RoIAlign gains from joint mask-training gains.

## Detail placement

Explain which quantization steps disappear and why spatial layout must survive. Separate the whole-image backbone from the per-RoI head. The keypoint extension demonstrates flexibility through a new output interpretation, not a completely new system.

## Interpretation

Adding the keypoint task can slightly reduce box and mask accuracy even though joint prediction is useful. A common framework does not imply mutual improvement for every task. This source belongs here for detector alignment and joint-training craft; its primary task is instance segmentation.
