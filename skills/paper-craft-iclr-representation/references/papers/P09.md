## Writing move: Frame the design around a useful interface constraint

FILIP poses a concrete tension: global features support independent encoding, while finer interactions can require joint processing. Token-wise late interaction offers a way to retain separately computed features while changing the alignment signal. The paper credits late interaction from retrieval and explains the cross-modal modifications, including excluding padding and averaging token scores.

## Experimental logic

Table 4 isolates late interaction and the two augmentation choices on the same filtered dataset. Table 5 then exposes the cost of full token matching and the tradeoff from reducing dimension, precision, and token count. Together these explain both the quality gain and how the proposed design becomes practical.

## Detail placement

Keep the token matching operation, directional score aggregation, and remaining comparison cost in the main method. State pretraining data and prompt ensembles alongside zero-shot results. Longer prompt inventories, model configurations, and extra alignment examples belong in supporting material.

## Interpretation

Offline feature computation does not reduce matching to a single-vector dot product. Different pretraining corpora mean the large-model comparison alone cannot isolate data efficiency. The selected alignment examples do not establish a localization benchmark. The final efficient setting trades a little accuracy for reduced cost relative to full token matching.
