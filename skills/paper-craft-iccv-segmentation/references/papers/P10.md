## Writing move: Let the task definition organize model, data, and evaluation

Segment Anything frames task, model, and data as interdependent decisions. A valid response to an ambiguous prompt demands multiple mask outputs; interactive use demands reusable image embeddings; scarce masks motivate an iterative annotation process. The three contributions form one argument.

## Experimental logic

Single-point transfer evaluates the defining task across diverse datasets. Automatic overlap, an oracle choice among masks, and human judgments answer different questions because a valid mask need not match the sole annotation. More-point evaluation reveals where the advantage narrows. The data ablation finds roughly comparable results with one million versus eleven million images; this supports a useful smaller-data regime rather than an unlimited scaling claim.

## Detail placement

State whether the image embedding is precomputed when describing interaction speed. Explain prompt source and ambiguity before reporting quality. Text-to-mask uses a modified training procedure and is presented as exploratory; it is not a default capability of every released model. The human study specifies validity, boundary quality, and prompt correspondence, with matched inputs and randomized rating jobs.

## Interpretation

The model wins automatic single-point comparisons on 16 of 23 datasets, not all. Oracle selection uses ground truth and is diagnostic. Fine structures and high-IoU interaction remain limitations. The foundation-model positioning is an ambition grounded in transfer evidence, not proof that all segmentation tasks are solved.
