## Writing move: Explain efficiency through an information path

CCNet replaces dense pairwise attention with two recurrent criss-cross passes. Following one pixel through an intermediate row or column shows how sparse operations provide full-image connectivity. The reader can understand the saving before seeing complexity notation.

## Experimental logic

One, two, and three passes test the reach-versus-cost argument. Context-module comparisons and horizontal/vertical alternatives test whether the specific sparse pattern matters. The resource table concerns the added attention computation at a stated resolution.

## Detail placement

Keep the two-hop path and shared parameters in the main text. State feature-map size when quoting memory or FLOPs. Whole-model runtime is a different quantity from attention-module savings.

## Interpretation

Full connectivity is not numerical equivalence to dense attention. A third pass adds a small gain at additional cost; two passes are a tradeoff, not the accuracy maximum. Attention examples illustrate selected relationships, rather than proving semantic understanding everywhere.
