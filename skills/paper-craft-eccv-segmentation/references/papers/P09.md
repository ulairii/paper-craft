## Writing move: Repair the granularity mismatch before adding adaptation machinery

The simple open-vocabulary baseline identifies a mismatch between CLIP's image-level recognition and pixel-level segmentation. Generating masks and classifying masked image crops brings recognition closer to the granularity of pretraining. Explain why this interface should help before introducing prompts and score ensembling.

## Experimental logic

The experiments separate cross-dataset transfer from seen/unseen splits. An oracle region classifier examines proposal quality, while encoder and pretraining comparisons distinguish the two-stage formulation from access to larger pretraining data. The appendix strengthens the FCN baseline with sliding windows instead of relying on an obviously weak implementation.

## Detail placement

State which classes have segmentation labels and what external pretraining is used. Keep learned and frozen classifier roles visible because they explain the seen/unseen complementarity. Background filling changes performance materially; include the crop construction when adapting the method, while prompt-length sweeps can remain supplementary.

## Interpretation

A small overall mIoU gap to supervised training can conceal a large unseen-class gap because seen classes dominate the label set. Thing/stuff breakdowns and alternative splits make this visible. Learned visual prompts fail in the supplement, while text prompts help: avoid turning one successful adaptation into a claim that all prompt learning works.
