## Writing move: Connect a computational factorization to the spatial question it enables

Axial-DeepLab begins with the tension between local efficiency and long-range interactions. Sequential attention along height and width makes broader context feasible; position-sensitive terms retain spatial information. Explain these as two connected design choices rather than presenting attention as inherently superior to convolution.

## Experimental logic

Classification experiments establish the building block, while segmentation experiments test its value at larger spatial scales. Attention-span ablations directly address the receptive-field motivation. The scale stress test complements ordinary benchmark results by evaluating resolutions outside the training setting.

## Detail placement

Distinguish the fully attentional classification variant from segmentation models retaining convolutional stems and decoders. State the actual span when memory limits prevent global attention. The striking computation comparison combines a single-scale small model with a multi-scale baseline, so keep those configurations attached to the ratio.

## Interpretation

The discussion explicitly reports slower execution than convolution despite fewer multiply-adds. Learn this precise separation rather than translating computational savings into speed. Sequential axial attention gives a global communication path when spans permit it; it is not numerically identical to unrestricted 2D attention.
