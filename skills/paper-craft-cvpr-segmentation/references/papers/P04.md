## Writing move: Distinguish access to context from using context

EncNet asks whether a larger receptive field is the same as capturing useful scene context. An annotator who first learns that an image shows a bedroom offers an intuitive explanation: scene information changes which categories are plausible. Encoding feature statistics and using them to scale channels operationalizes that intuition.

## Experimental logic

The encoding module and category-presence loss receive separate comparisons. The codeword study includes global average pooling as an alternative, connecting the experiment to the representation choice. Examples of window-versus-door and sand-versus-earth confusion make the proposed use of context recognizable.

## Detail placement

Explain that category-presence targets come from the existing masks, and explain why a presence loss weights categories differently from a pixel loss. Introduce the encoding equation after the role of the dictionary is clear. The shallow classification extension belongs after the main segmentation argument.

## Interpretation

Scene-dependent scaling is not a hard rule forbidding unusual objects. Keep the intuitive bedroom example separate from the actual learned operation. When discussing small categories, distinguish the loss-design motivation from a claim that every small object improves.
