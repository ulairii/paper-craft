# P07: FuzzGuard: Filtering out Unreachable Inputs in Directed Grey-box Fuzzing through Deep Learning

Peiyuan Zong; Tao Lv; Dawei Wang; Zizhuang Deng; Ruigang Liang; Kai Chen. **USENIX Security 2020**. [Official paper](https://www.usenix.org/conference/usenixsecurity20/presentation/zong) · [Full text](https://www.usenix.org/system/files/sec20-zong.pdf).

Source locations: Sections 1–6; dominator stepping and sampling design; Section 6.2 timing protocol and feature analysis; appendix.

## Writing move: Give a learned model a specific decision in the system

FuzzGuard places learning at a concrete decision: whether a generated input is likely to reach a directed-fuzzing target and is worth executing. Cold-start imbalance, changing inputs, and model cost lead to corresponding design choices. This challenge-to-design mapping makes the system contribution clear even though the neural architecture itself is familiar.

## Experimental logic

The evaluation connects training onset, prediction behavior, and avoided execution work. Ablations of stepping and representative sampling explain intermediate effects rather than only an aggregate score. The timing protocol replays input sequences previously generated by AFLGo and subtracts skipped execution time while adding model costs. That protocol supports an execution-filtering argument with a specific experimental boundary.

## Detail placement

Keep the dominator labels, model-update rule, deferred-input pool, and GPU resources near the method and evaluation. Explain replayed sequences before interpreting time savings. Feature-masking examples can illustrate a learned association; architecture minutiae and full target lists can follow the main decision loop.

## Interpretation

A large saving on a sequence ending in a timeout is not a demonstrated speedup in discovering that bug. Reachability false negatives are not the same as the probability of missing a vulnerability. Reconsidering deferred inputs mitigates mistakes without guaranteeing none. Feature examples do not establish complete semantic understanding, and learning a new mutation strategy remains a separate proposal.
