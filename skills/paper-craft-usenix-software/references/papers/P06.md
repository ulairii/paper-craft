# P06: Symbolic execution with SymCC: Don't interpret, compile!

Sebastian Poeplau; Aurélien Francillon. **USENIX Security 2020**. [Official paper](https://www.usenix.org/conference/usenixsecurity20/presentation/poeplau) · [Full text](https://www.usenix.org/system/files/sec20-poeplau.pdf).

Source locations: Sections 1–6; compilation example, execution/backend decomposition and fuzzing results; complete appendix.

## Writing move: Make the component boundary sharpen the novelty

SymCC uses the familiar distinction between compilation and interpretation to explain an execution-engine contribution. It credits earlier source instrumentation and identifies the compiler-IR stage as a useful combination of flexibility and implementation scope. A small transformed-code example connects this architectural decision to runtime behavior. The method improves one part of symbolic execution rather than claiming to replace every part.

## Experimental logic

Reusing QSYM’s symbolic backend makes the execution comparison informative. The paper separates concrete execution, symbolic work, and solver time before reporting hybrid-fuzzing outcomes. Programs dominated by the solver explain why large execution improvements can become small end-to-end gains. Compilation cost and binary size expose the price paid outside the main execution loop.

## Detail placement

Keep the reused backend, supported language implementation, treatment of unavailable libraries, and timing boundaries visible. Explain the concrete-versus-symbolic comparison before quoting speedups. The supplementary excluded case matters when discussing the comparison population; full compiler settings need not dominate the method narrative.

## Interpretation

LLVM compatibility suggests possible language extensions but does not mean every LLVM language was implemented. Concrete handling of an unavailable library loses symbolic analysis there. The older OpenJPEG crash comparison does not show a significant difference even though later testing finds new bugs. Present component efficiency and practical discoveries as related but distinct evidence.
