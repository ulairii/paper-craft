## Writing lesson: Replace a broad capability question with an understandable decomposition

Section 4 separates judging an answer, producing a critique, and using that critique. Each distinction gives a result an explanatory role. The reader learns which part of self-verification matters, rather than receiving only an aggregate judgment about the whole pipeline.

**Borrow this move.** When a capability combines several behaviors, name those behaviors in plain language and use them to organize the paper. Return from the individual findings to explain the overall behavior once the pieces are clear.

**Original writing illustration.** “Recognizing an error, explaining it, and correcting it are different tasks” opens an analytical paragraph more clearly than “We investigate the multifaceted limitations of autonomous metacognitive reasoning.”

## Supporting reading notes

**Narrative and paragraphs.** Section 4 (from p. 6) separates judging correctness, generating correct critiques, and revising from those critiques, using verifiable tasks to measure each. This decomposition avoids inferring the absence of every intermediate capability from a single final failure.

**Experimental logic.** Table 1 (p. 7) compares LLM feedback, rich/first-error/binary feedback from a sound verifier, and resampling. Table 2 (p. 8) separates verifier false positives from false negatives. Aggregate verification accuracy can hide frequent rejection of correct answers, so explain how the direction of errors affects stopping and selection.

**Interpretation.** The title does not support the claim that critique is never useful. Table 1 shows LLM self-critique improving Blocksworld from 40 to 55, and the content of external feedback also changes performance. Strengthening CoT verification prompts in Appendix A.1 (pp. 14–15) substantially improves the Game of 24 pipeline. Prompt sensitivity is a counterexample that must remain visible.

**Detail placement.** State whether a verifier is a deployable rule-based program or an oracle using hidden test answers; these are different sources of information. Figure 2 (p. 7) depends on stopping rules, so monotonic curves alone do not establish learning. Appendix cost comparisons use queries as a proxy, not necessarily matched FLOPs. Complete critique records can go in the appendix; the verification confusion matrix belongs in the main text.

**Transferable recommendation.** Localize a negative result to the failing component and explain its effect on decisions. Do not transfer conclusions from formally verifiable tasks unconditionally to open-ended prose revision.
