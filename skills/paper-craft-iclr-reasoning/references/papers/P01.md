## 采样与聚合：把最小改动写成明确机制

**故事与段落。** 引言先承认 CoT 的能力，再把缺口限定为 greedy decoding 只保留一条路径；§2/Fig.1（p.2）用“多样路径—答案归并—多数选择”解释改动。创新卖点是改变解码与聚合，而非暗示训练了新模型。读者需要先理解为什么路径可以不同、答案可以相同，再看形式化表达。

**实验如何接住故事。** §3.2/Tables 2–3（p.5）展示跨模型、任务效果；Fig.2（p.6）回答增加样本是否持续有用；§3.4/Fig.3 与 Table 6（p.7）用 sample-and-rank、beam search 对照区分“多生成”与“如何聚合/保持多样性”。§2/Table 1（p.3）的聚合变体比堆更多模型更直接检验机制。

**如何解释。** 一致性与正确率相关（Fig.5，p.8），不能据此声称置信度已经校准。§5（p.9）承认最终答案正确时，中间推理仍可能错误。因此正文可以卖稳健答案选择，不能卖推理忠实性保证。

**细节取舍。** 正文必须说明样本数、相同 prompt、答案等价归并规则、采样参数与计算代价；§3.2 的重复采样统计不能写成独立训练种子。完整 prompt 与替代 prompt 稳健性可放附录 A.1.2/Table 9（p.17）。无需重新科普 Transformer。

**迁移规则。** 若你的贡献只改选择器，主实验要固定候选集合；若同时改变候选分布，再加生成器控制。此规则是由原文对照设计蒸馏的建议，并非原文证明所有任务都应多数投票。
