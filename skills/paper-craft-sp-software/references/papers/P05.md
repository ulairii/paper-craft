## Writing move: Explain what a learned representation makes possible

NEUZZ presents a mismatch between discrete program behavior and gradient-based search, then uses a surrogate to connect them. This supplies a reason for learning a model beyond adding machine learning to fuzzing. The model predicts branch feedback; the mutation procedure uses its input gradients. Keeping these two tasks separate makes the contribution recognizable.

## Experimental logic

The fixed-mutation-budget comparison with an RNN-based filter asks about input-generation efficiency, while training time addresses a different cost. Linear, nonlinear, and incrementally refined models explain the choice of representation. Bug cases connect the mutation of extreme values to allocation, overflow, and assertion behavior. The small zlib result also illustrates a setting with little remaining coverage to gain.

## Detail placement

Keep initial corpus collection, GPU use, and the definition of additional edge coverage in the main text. LAVA-M and CGC experiments add special comparison instrumentation and local search; those ingredients materially define the method evaluated. A long general optimization tutorial can be shortened to the intuition required by the running example.

## Interpretation

The universal approximation theorem does not guarantee useful gradients for every program. The ten baseline fuzzers are compared across different datasets, not all on every target. Model prediction accuracy and overall performance alone do not isolate the causal value of gradient ranking. Use the paper to learn representation-centered exposition while keeping empirical claims tied to the actual comparison.
