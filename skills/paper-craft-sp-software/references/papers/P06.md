# P06: ProFuzzer: On-the-fly Input Type Probing for Better Zero-day Vulnerability Discovery

Wei You; Xueqiang Wang; Shiqing Ma; Jianjun Huang; Xiangyu Zhang; XiaoFeng Wang; Bin Liang. **IEEE S&P 2019**. [Paper record](https://www.ieee-security.org/TC/SP2019/program-papers.html#sp19_45) · [Official venue listing](https://www.ieee-security.org/TC/SP2019/program-papers.html) · [Full text](https://xw48.github.io/files/you2019profuzzer.pdf).

Source locations: Sections I–VII; BMP example, Tables I–VI; Appendices A–F.

## Writing move: Define only the semantics the task needs

ProFuzzer explains that a complete file specification is not the same as useful knowledge for testing one implementation. Image resolution can matter to rendering yet be ignored by a converter. Conversely, nominal image data can affect loop behavior. The same BMP input introduces the problem, the field types, their observed signatures, and the resulting mutations.

## Experimental logic

Field-identification accuracy asks whether probing recovers its intended information. Mutation effectiveness and coverage ask whether that information helps. Seed-count experiments explain which field combinations become reachable. The Exiv2 and ZzipLib cases trace a field-level change through program behavior to a fault, making the practical benefit more persuasive than an inventory alone.

## Detail placement

Keep deterministic execution, usable seeds, early error behavior, and the six task-specific field roles in the main text. Explain that exploitation rules were manually derived from prior examples. Complete per-byte plots and discovery inventories can follow the main story; one field-to-fault case deserves space in it.

## Interpretation

Probing costs time and can misclassify checksum-protected data. The paper reports much weaker LAVA-M results than Angora and QSYM, even after benchmark-specific adaptation. This contrast clarifies the contribution’s emphasis on implementation-dependent field behavior. A strong draft can explain that difference without dismissing the benchmark or claiming universally accurate semantics.
