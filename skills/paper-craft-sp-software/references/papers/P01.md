# P01: Skyfire: Data-Driven Seed Generation for Fuzzing

Junjie Wang; Bihuan Chen; Lei Wei; Yang Liu. **IEEE S&P 2017**. [Paper record](https://www.ieee-security.org/TC/SP2017/program-papers.html#oakland17-42) · [Official venue listing](https://www.ieee-security.org/TC/SP2017/program-papers.html) · [Full text](https://www.ieee-security.org/TC/SP2017/papers/42.pdf).

Source locations: Sections I–VI; running XSL example, semantic-validity experiment, coverage analysis and vulnerability case.

## Writing move: Make a processing bottleneck explain the representation

Skyfire separates syntax checking, semantic checking, and application processing. That sequence makes the problem more specific than generating valid files: seeds must pass the checks that prevent mutations from reaching useful code. Context learned from examples supplies the missing information. The running XSL example carries the reader from a parsed tree to a production rule and then to generated input.

## Experimental logic

The grammar-only comparison measures semantic acceptance, directly answering the motivating question. Coverage before and after subsequent mutation explains a complementary role: a stronger initial corpus can leave less incremental coverage for AFL while still helping it expose faults. The vulnerability case shows valid generated input becoming useful material for a later invalid mutation.

## Detail placement

Keep the supplied grammar, learned context, and role of subsequent mutation in the main text. Equal numbers of generated inputs do not imply equally sized minimized seed sets. Explain which stages the generator supports; the learned context does not capture every semantic rule. Extensive file-level coverage grids can accompany the main comparison in supporting material.

## Interpretation

The paper reports separate counts for memory bugs, vulnerabilities, CVEs, and denial-of-service findings. Its long discovery campaigns have different durations across input families. Borrow the complementary-generation argument without describing every finding as a confirmed new vulnerability or treating all percentage changes as relative gains.
