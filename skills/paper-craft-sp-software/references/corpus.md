# IEEE S&P software security: source papers

Ten accepted IEEE Symposium on Security and Privacy papers on fuzzing, program analysis, input structure, hybrid search, state feedback, and USB gadget testing.

All ten main texts and the appendices present in the consulted PDFs were read. Exact reading coverage and PDF identities are recorded in the metadata. Figure discussion uses text, captions and extracted labels, not visual-style analysis. These notes interpret writing craft in accepted papers; they do not establish what caused acceptance.

Official conference programs establish publication venue; full texts include official and author-hosted copies. BibTeX is compiled from those program records and omits unestablished fields.
