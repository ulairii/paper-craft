# P04: Stolen Memories: Leveraging Model Memorization for Calibrated White-Box Membership Inference

Klas Leino; Matt Fredrikson. **USENIX Security 2020**. [Official paper](https://www.usenix.org/conference/usenixsecurity20/presentation/leino) · [Full text](https://www.usenix.org/system/files/sec20-leino.pdf).

Source locations: Sections 1–7; illustrative feature example, Gaussian model, calibration and deep-model experiments; Appendix A.

## Writing move: Build an unexpected leakage story from a small explanatory model

Stolen Memories explains why a correctly classified example can still reveal membership through the particular features used to recognize it. The feature example motivates a simplified probabilistic model; its analytic insight then guides a practical white-box attack. The progression from an idealized case to an approximation gives the reader a reason to care about the mathematics.

## Experimental logic

Comparisons with prediction-based attacks show what internal access adds. Calibration trades recall for precision instead of reducing the result to overall accuracy. Layer combinations and training-set-size experiments investigate where the signal comes from. The simple correctness baseline helps distinguish memorization evidence from ordinary train–test performance differences.

## Detail placement

Keep model access, true labels, same-population auxiliary data, and the membership prior near the attack definition. Explain how fixing the target feature extractor aligns representations. Place the full derivation in the appendix, while retaining the intuition linking feature use to membership in the main text. Describe which subset a high-precision result covers.

## Interpretation

Optimality in the Gaussian model does not make the deep-network approximation Bayes-optimal. Precision measured with balanced members and nonmembers need not persist under a different prior. Small generalization gaps can coexist with the reported leakage; that finding is more informative than claiming all well-performing models expose their entire training set.
