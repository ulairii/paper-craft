## Writing move: Define exactly which restriction is removed

Group-Free detection targets hard assignment of points to an object proposal. Attention lets encoded points contribute softly to object features, followed by iterative refinement using updated box positions. The term group-free has a local meaning: the backbone still uses point grouping. Defining the removed restriction makes the novelty easier to trust.

## Experimental logic

A same-stage comparison with grouping alternatives isolates the aggregation change. Position-encoding ablations distinguish static positions from iterative center-and-size information. Sampling choices and multi-stage ensembling answer secondary design questions. The stronger ensemble gain on SUN RGB-D than ScanNet invites a scan-completeness explanation, but does not establish it causally.

## Detail placement

Define an object query, the encoded point set it attends to, and how predicted boxes update positional information. Keep manual assignment and NMS in the description instead of implying DETR's complete training and inference formulation. Report best and mean statistics by their actual definitions once, without turning the narrative into bookkeeping.

## Interpretation

Different experiments can reach different conclusions about set losses because their representations and training setups differ. Explain the successful combination here. Avoid claiming that all point grouping is unnecessary or that one assignment rule is universally superior.
