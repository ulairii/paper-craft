## Writing move: Sell simplification as an informative baseline

3DETR asks how far a comparatively simple transformer can go in 3D detection. Non-parametric queries and Fourier position features make the adaptation concrete. The strongest local-attention variant is named separately. The value is an understandable baseline and reusable design, not a claim that every geometric prior has disappeared.

## Experimental logic

Encoder, decoder, and loss substitutions reveal which components work together. A decoder swap that also requires a different loss is a compatibility comparison, not an isolated module effect. Query-count and decoder-depth experiments distinguish changing inference computation in one trained model from training a larger model. The NMS comparison measures sensitivity even though the default uses NMS.

## Detail placement

State the initial point aggregation and the masked variant's locality. Credit improvements from the common training setup when comparing reimplemented baselines. Put detailed schedules in setup, but keep the generic-versus-masked distinction beside headline results because it changes the story.

## Interpretation

The masked variant's large ScanNet improvement does not imply dominance on every SUN RGB-D metric. Separately trained shape-classification experiments support architectural versatility, not zero-shot transfer of the detector. A clear competitive baseline can be a compelling result without universal superiority.
