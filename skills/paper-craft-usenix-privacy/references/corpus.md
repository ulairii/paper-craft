# USENIX Security privacy and measurement: source papers

Ten accepted USENIX Security papers on cross-device tracking, browser and extension fingerprinting, cookie policies, user exposure, and tracking defenses. This collection focuses on browser privacy and web measurement.

All ten main texts and relevant appendices were read; exact coverage is recorded in the metadata. Most PDFs include a USENIX cover as page 1; Rendered Private starts its main text on PDF page 1. Figure discussion uses text and captions. These notes interpret writing craft in published papers, rather than establish what caused acceptance.
