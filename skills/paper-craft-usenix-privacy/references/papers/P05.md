# P05: Everyone is Different: Client-side Diversification for Defending Against Extension Fingerprinting

Erik Trickel; Oleksii Starov; Alexandros Kapravelos; Nick Nikiforakis; Adam Doupé. **USENIX Security 2019**. [Official paper](https://www.usenix.org/conference/usenixsecurity19/presentation/trickel) · [Full text](https://www.usenix.org/system/files/sec19-trickel.pdf).

Source locations: Sections 1–7; identifier and structure diversification, compatibility and attack evaluations.

## Writing move: Connect each privacy mechanism to the functionality it preserves

CloakX frames client-side diversification as a way to change recognizable extension artifacts while preserving their useful behavior. Static rewriting and runtime handling solve different reference problems. A context-sensitive identifier example explains why simple replacement is insufficient. The writing makes the mechanism intelligible through the relationship between an identifier and the code that uses it.

## Experimental logic

Broad automated error checks and a smaller manual functionality study provide complementary evidence. General fingerprinting and targeted behavioral attacks test different protection scopes. Reporting that some targeted extensions remain detectable explains what identifier diversification leaves visible. The implementation-cost analysis has a clear role only when tied to extension loading and rewriting.

## Detail placement

Keep eligibility filters, what is randomized, when randomization changes, and the distinction between structural and behavioral detection visible. Explain the manual sample and its exclusions. Complete rewrite rules and extension inventories belong later. Error-free execution is useful evidence but does not replace functional testing.

## Interpretation

The 145 passing manual cases out of 150 have a different meaning from the large automated error-log result. Eleven of twenty targeted extensions remain detectable in the reported behavioral tests. Stable rewritten artifacts need not provide longitudinal unlinkability. Sell the protection supplied by the changed representation, with remaining behavior motivating complementary defenses.
