## Writing move: Expand the threat model through an ordinary interaction

Human Touch uses text selection and translation to reveal a missing dimension in passive extension analysis. Browser, mouse, and keyboard templates organize the new capability. The static analysis exists to discover useful actions; dynamic exercising shows their consequences. This sequence sells a broader observation model with a familiar example before introducing automation.

## Experimental logic

The study distinguishes device-level simulated user actions from events a page can generate itself. The latter experiment finds 1,513 triggerable extensions among 2,234 eligible cases. Comparisons across historical collections establish additional coverage, with explicit distinctions between unique extensions and versions. Testing an event-provenance guard connects the discovered cause to a limited remedy.

## Detail placement

Keep the action category, visible behavior, attacker control, and comparison population in the main text. Browser toolbar and context-menu actions are not ordinary page-generated events. State when a prior technique is represented by an upper bound instead of a rerun. Complete event lists and guard code can go in the appendix.

## Interpretation

The 4,971 unique extensions are not a sum of all version entries. The synthetic-event result does not mean every human-triggered extension can be activated without a user. The guard addresses synthetic events and does not conceal effects of genuine interactions. Small-subset attack timing and an extrapolated collection-wide estimate should remain distinguishable.
