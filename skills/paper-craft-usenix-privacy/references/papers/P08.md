Soroush Karami; Faezeh Kalantari; Mehrnoosh Zaeifi; Xavier J. Maso; Erik Trickel; Panagiotis Ilia; Yan Shoshitaishvili; Adam Doupé; Jason Polakis. **USENIX Security 2022**. ## Writing move: Make a design invariant organize both the method and residual cases

Simulacrum separates the DOM the user sees from the DOM the page can inspect. Selective mirroring explains the central invariant: page and user changes propagate, extension artifacts do not. Four classes of API behavior explain why a general wrapper needs different handling for queries, updates, and visible state. The method’s complexity follows from preserving this simple relationship.

## Experimental logic

Testing against the original detector gives 95.86% protection; adapting the detector to partial fingerprints reduces it to 95.37%. The difference reveals residual information. Early execution and page-injected scripts explain remaining cases. Website functionality, extension functionality, and loading cost supply distinct evidence about the privacy–compatibility tradeoff.

## Detail placement

Keep the two DOM roles, synchronization rule, execution timing, and representative API cases in the main text. The original-versus-adapted detector comparison deserves visible interpretation. Put full wrappers and interface inventories in the appendix. State the populations for performance statistics: the 895 ms mean is for pages with positive overhead.

## Interpretation

The manual sample has major breakage on six of fifty sites and minor breakage on five; these are useful deployment findings, not negligible details. Fifty tested protected extensions retaining functionality does not establish universal compatibility. Proposed developer changes and browser integration are different from protection supplied by the current prototype. Timing channels remain outside its scope.
