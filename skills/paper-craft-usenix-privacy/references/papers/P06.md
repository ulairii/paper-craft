# P06: Fingerprinting in Style: Detecting Browser Extensions via Injected Style Sheets

Pierre Laperdrix; Oleksii Starov; Quan Chen; Alexandros Kapravelos; Nick Nikiforakis. **USENIX Security 2021**. [Official paper](https://www.usenix.org/conference/usenixsecurity21/presentation/laperdrix) · [Full text](https://www.usenix.org/system/files/sec21-laperdrix.pdf).

Source locations: Sections 1–8; Dr.Web example, trigger pipeline and comparisons; Appendices A–B.

## Writing move: Explain a new observation channel with one trigger and a control

Fingerprinting in Style starts from a useful distinction: a page cannot directly inspect an extension’s hidden stylesheet, but can observe its effects. A crafted element turns that effect into a detectable signal. The pipeline then follows naturally: extract candidate rules, construct triggers, observe stable changes, and distinguish extensions with overlapping styles.

## Experimental logic

A matching baseline element without the trigger identifiers helps attribute a style change. Repetition tests stability; cross-extension comparisons resolve collisions. The study finds 4,446 uniquely detectable extensions and identifies 1,074 beyond prior vectors. The defense evaluation addresses load time, JavaScript errors, and visible output, while the longitudinal analysis concerns extension versions.

## Detail placement

Keep the trigger, baseline, collision handling, and store-to-eligible-to-detectable denominators in the main text. Explain the exclusion of interactions such as hover or focus. A full property inventory belongs in the appendix. Distinguish the evaluated Shadow DOM extension from the proposed native-browser blueprint.

## Interpretation

The 3.8% figure is a fraction of the crawled store, not a fraction of identifiable people. Widespread use of getComputedStyle is not evidence that the new attack is deployed. A twenty-extension timing test does not measure full-store detection. The defense’s page tests address the tested interfaces and pages, not every browser observation channel.
