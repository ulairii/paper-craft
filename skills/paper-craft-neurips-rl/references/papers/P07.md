## Writing move: Explain a generative model through the decisions made by its decoder

Trajectory Transformer treats states, actions, and rewards as one sequence, then makes decoding the bridge to behavior. Likelihood-based search supports imitation, while reward-aware search supports planning. The contribution becomes legible through this model–decoder relationship. Joint trajectory modeling and planning distinguish the story from return-conditioned action prediction.

## Experimental logic

Prediction experiments precede control, establishing what the model captures. A Markovian Transformer performs well in fully observed settings, while masked observations make history more useful. Uniform and quantile discretization expose a consequential representation choice. AntMaze results use an IQL critic to guide search, showing a useful combination with value learning.

## Detail placement

Keep discretization, beam scoring, action restrictions, and any external critic in the main account. The reported fifteen evaluations comprise five trained models with three rollouts each. Explain planning latency when discussing practicality. Full architecture and decoding settings can follow the conceptual model.

## Interpretation

The strongest maze result does not eliminate Bellman-based learning because it uses an IQL value function. Longer context is not established as the sole reason for predictive quality. Conceptual unification does not imply faster online action selection: planning can take seconds per action. The useful claim is that sequence models support multiple decision procedures.
