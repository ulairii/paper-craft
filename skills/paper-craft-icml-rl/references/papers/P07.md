# P07: CURL: Contrastive Unsupervised Representations for Reinforcement Learning

Laskin, Michael; Srinivas, Aravind; Abbeel, Pieter. **ICML 2020**. [Official paper](https://proceedings.mlr.press/v119/laskin20a.html) · [Full text](https://proceedings.mlr.press/v119/laskin20a/laskin20a.pdf).

Source locations: Sections 1, 4–7; Tables 1–2; supplement A–B and E.

## Writing move: Use a privileged reference to make an efficiency gap concrete

CURL motivates visual RL through the gap between learning from pixels and learning from state features. It then explains why static-image contrastive learning cannot simply be assumed to work in an online, changing dataset. The architecture is presented as a small set of choices with a purpose, including temporally consistent crops and shared representation learning. This connects borrowed machinery to the new setting.

## Experimental logic

The paper distinguishes return at a fixed budget from the number of steps needed to reach a reference return. Six tasks support detailed pixel-baseline comparisons; sixteen support a broader state-reference comparison. Ablations on frame stacks and critic gradients ask what information the representation uses.

## Detail placement

State whether steps mean environment frames or agent decisions. Keep the privileged state input visible in labels, and describe the shared encoder's gradient sources. Full augmentation code is secondary. Preserve relevant exceptions: the Atari supplement changes the contrastive coefficient for four games despite the broad simplicity narrative.

## Interpretation

State-based SAC is an informative reference, not a mathematical upper bound. Higher median Atari performance coexists with a lower mean than SimPLe. The state-prediction probe suggests an observability explanation for remaining gaps; it does not prove that missing information is their sole cause.
