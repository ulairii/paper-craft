Hansen, Nicklas A; Su, Hao; Wang, Xiaolong. **ICML 2022**. [Official paper](https://proceedings.mlr.press/v162/hansen22a.html) · [Full text](https://proceedings.mlr.press/v162/hansen22a/hansen22a.pdf).

## Writing move: Explain the division of labor before introducing the losses

TD-MPC assigns short-term consequences to model rollouts and longer-term return to a value function. A concrete locomotion example makes that division understandable before the full objective appears. The paper describes inference first, then explains how training supplies the quantities inference needs. Use this order when a system combines planning, representations, and value learning.

## Experimental logic

Task families test distinct promises: difficult control, pixel observations, transfer, and multiple modalities. Planning-budget sweeps use already trained models to examine the value of more inference computation. Time-to-solve and time per fixed number of environment steps reveal different efficiency tradeoffs.

## Detail placement

Keep the rollout horizon, terminal-value role, and task-oriented learning targets in the method. Put full network specifications in the appendix. Budget differences matter beside the simulator comparison: a ground-truth model with a limited planner and no terminal value is not an oracle upper bound.

## Interpretation

The source supports strong state-control results and competitive, uneven pixel results. It uses more computation per fixed number of samples than SAC while reaching selected thresholds in similar time. Transfer experiments involve online finetuning between related tasks; they do not establish a task-independent world model or real-robot deployment.
