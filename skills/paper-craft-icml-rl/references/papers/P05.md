# P05: Addressing Function Approximation Error in Actor-Critic Methods

Fujimoto, Scott; van Hoof, Herke; Meger, David. **ICML 2018**. [Official paper](https://proceedings.mlr.press/v80/fujimoto18a.html) · [Full text](https://proceedings.mlr.press/v80/fujimoto18a/fujimoto18a.pdf).

## Writing move: Let a failure diagnosis generate the algorithm

TD3 shows a failure before presenting its remedy: estimated values drift above rollout-based estimates, and straightforward adaptations of earlier corrections remain inadequate. The three changes then answer connected problems—overestimation, actor–critic feedback, and narrow value peaks. Borrow this causal order to make a multi-component method feel necessary rather than assembled.

## Experimental logic

The value diagnostic precedes return comparisons. Fixed-policy versus learned-policy experiments expose the feedback problem. Adding components to a retuned baseline and removing them from the complete method reveals interactions; the same component need not help equally in isolation and in combination.

## Detail placement

Keep the diagnostic's reference value definition and each component's role in the main text. Put the complete architecture comparison and tabular convergence proof in supporting material. The retuned DDPG baseline belongs in the results because it tells the reader how much improvement comes from the proposed changes.

## Interpretation

Table 2 contains task-dependent component effects, so avoid saying every component is indispensable everywhere. Table 1 uses a maximum-average statistic, while Table 2 averages late evaluations. Supplement D explains that the SAC comparison uses an earlier variant and a different update budget from its original results; a historical comparison is not timeless algorithm dominance.
