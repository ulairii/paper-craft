## Writing move: Organize the method around two practical obstacles

SAC's opening identifies sample cost and brittle learning as separate obstacles. Its ingredients then have clear jobs: off-policy updates reuse experience, and an entropy-based stochastic actor supports exploration and stable learning. Related work explains which ingredients already existed and what the formulation combines. This is a useful way to sell an integration without pretending every component is new.

## Experimental logic

Return curves address sample efficiency and final performance; individual runs on a difficult task make the stability argument tangible. Reward-scale and target-update sweeps explain how the algorithm behaves, rather than merely documenting chosen constants. Harder tasks matter because brittle methods become harder to tune there.

## Detail placement

Keep the entropy-augmented objective and the evaluation policy explicit: the plotted returns exclude entropy, and SAC uses mean actions for evaluation. Put the bounded-action density calculation and full network settings in the supplement. The 2018 paper uses a separate value network and tuned reward scales; do not silently substitute later SAC variants.

## Interpretation

The policy-iteration result is derived under tabular assumptions; the neural implementation is an approximation. Stability across the reported seeds coexists with reward-scale sensitivity. The deterministic ablation changes several coordinated features, so describe the comparison as a variant comparison rather than an isolated proof about entropy alone.
