## Writing move: Let a mathematical reformulation solve a visible obstacle

PointConv starts from continuous convolution on irregular samples and introduces density-dependent weighting. It then makes the efficient reformulation a central contribution: a direct implementation would create an impractically large weight tensor. The mathematical identity matters because it changes what can be computed.

## Experimental logic

The image-to-point experiment asks whether the operation can recover familiar convolutional behavior on a regular grid. This unusual extra task serves the definition of the method. Density comparisons distinguish learned density scaling from using raw inverse density, and representation-width experiments address the cost of the reformulation.

## Detail placement

Keep the derivation that changes memory requirements in the main text. It is part of the scientific explanation, not incidental implementation detail. Routine architecture variants can move to supplementary material. Explain the learned transformation of density estimates rather than equating the model with an unmodified Monte Carlo estimator.

## Interpretation

The discussion suggests that sampling may reduce density variation in deeper layers; that is an explanation to investigate, not a theorem about the trained network. RGB does not help every tested setting. Filter visualizations illustrate possible behavior without proving geometric invariance.
